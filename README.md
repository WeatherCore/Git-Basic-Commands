## PDF完整收录命令清单（文档全部内容含其解释说明）
git add、git blame、git branch、git checkout、git cherry-pick、git clone、git commit、git config、git diff、git fetch、git init、git log、git ls-files、git merge、git mv、git push、git pull、git reflog、git remote、git reset、git restore、git revert、git rm、git shortlog、git show、git status、git stash、git switch、git tag、git whatchanged

## 文档模块划分
1. 文件暂存/撤销：add、restore、rm、diff 全套参数
2. 分支操作：branch、checkout、switch、merge、cherry-pick 冲突处理命令
3. 远程仓库：clone、remote、fetch、pull、push、浅克隆/子模块克隆
4. 提交管理：commit、amend、squash、reflog、reset、revert 版本回滚方案
5. 临时储藏：stash 完整保存/恢复/清理指令
6. 版本标签：tag 本地+远程推送删除操作
7. 配置与日志：config全局配置、log可视化提交记录、blame追溯代码作者

不包含大型仓库三角协作、复杂PR流程、交互式rebase等高阶Git进阶操作（对应内容独立存放 Git-Advanced-Guide 仓库）
